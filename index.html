O Que e o Site

Este site reúne exercícios e desafios de HTML e CSS que desenvolvi durante meus estudos no curso de HTML e CSS do canal Curso em Vídeo. O objetivo do projeto é registrar minha evolução na programação e reunir, em um único lugar, as atividades que realizei ao longo do curso.

Como instalar

Para utilizar este projeto, é necessário usar um IDE, como o Visual Studio Code, ou o próprio Bloco de Notas. Também é necessário ter um navegador compatível com HTML5 e CSS3 para executar o projeto.
